## 인터뷰별 요약 (각 인터뷰 기록 아래에 붙인다)

```markdown

| 구분 | 내용 (원문 인용 포함) |
|---|---|
| Validates | ... "<인용>" |
| Invalidates | ... "<인용>" |
| Also Interesting | ... |
| 감정 신호 | 어떤 장면에서, 어떤 말투로 |

- 증거 등급: 과거 행동 / 구체적 일화 / 일반론 / 미래 의향 (가장 강한 것 하나)
- 문제 강도: 반드시 필요 / 있으면 좋음 / 필요 없음
- 기존 대안과 들인 비용: <무엇을, 월 얼마·몇 시간>
- 전환 계기: <있었다면 언제, 무엇>
- 고객 작용력
  - 밀어내는 힘 (현재 방식의 불만):
  - 끌어당기는 힘 (바라는 상태):
  - 관성 (지금 방식에 붙잡는 습관·익숙함):
  - 마찰 (새 방식으로 옮기기 어려운 이유):
- 인터뷰어 자기 점검: 유도 질문 n개, 미래 가정 질문 n개, 놓친 후속 질문
```
